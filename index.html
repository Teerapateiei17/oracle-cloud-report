Oracle Cloud Infrastructure

Oracle Cloud คืออะไร?

Oracle Cloud หรือ Oracle Cloud Infrastructure (OCI) เป็นแพลตฟอร์ม Cloud Computing ของ Oracle ที่ช่วยให้ผู้ใช้งานเลือกใช้ทรัพยากรด้าน IT ผ่าน Cloud โดยไม่จำเป็นต้องลงทุนจัดซื้อและดูแล Server หรือ Infrastructure ทั้งหมดด้วยตนเอง

Compute

ทรัพยากรประมวลผลสำหรับ Application

Database

บริการฐานข้อมูลบน Cloud

Storage

จัดเก็บข้อมูลหลายรูปแบบ

Security

ควบคุมสิทธิ์และรักษาความปลอดภัย

รองรับทั้งผู้ใช้ทั่วไป นักพัฒนา และองค์กร

OCI สามารถรองรับการทำงานร่วมกับเทคโนโลยีสมัยใหม่ เช่น Container, Kubernetes, Serverless, Big Data, Artificial Intelligence และ Machine Learning ทำให้สามารถนำไปสร้างระบบตั้งแต่เว็บไซต์ทั่วไปจนถึงระบบ Enterprise ขนาดใหญ่

OCI Ecosystem
Kubernetes Serverless Big Data AI / ML Enterprise Database

Function as a Service

OCI FunctionsServerless

SensorMonitoringAnalytics

Big Data & Analytics

BlockchainSupply ChainTransaction

Infrastructure

Data Center & Cloud Region

Oracle Cloud ใช้โครงสร้างพื้นฐานที่ประกอบด้วย Region และ Availability Domain เพื่อรองรับความพร้อมใช้งานและการออกแบบระบบที่ทนทาน

Region

พื้นที่ทางภูมิศาสตร์ที่ Oracle ให้บริการ Cloud

Availability Domain

กลุ่ม Data Center ภายใน Region

High Availability

ออกแบบระบบให้ทนต่อความเสียหายและรองรับ Disaster Recovery

หลายภูมิภาคทั่วโลก

รายงานยกตัวอย่าง Region ในสหรัฐอเมริกา แคนาดา ยุโรป ญี่ปุ่น สิงคโปร์ ออสเตรเลีย และอินเดีย

ลด Latency

การเลือก Region ที่เหมาะสมกับตำแหน่งผู้ใช้งานสามารถช่วยลดระยะทางในการส่งข้อมูลและอาจลด Latency

Disaster Recovery

สามารถเตรียมระบบสำรองในอีก Region เพื่อรองรับกรณี Region หลักไม่สามารถให้บริการได้

Pricing Model

รูปแบบการคิดค่าบริการ

ค่าใช้บริการขึ้นอยู่กับประเภทและปริมาณทรัพยากรที่เลือกใช้ เช่น CPU, Memory, Storage, Network และ Database

Pay-as-you-go

จ่ายค่าบริการตามปริมาณทรัพยากรและระยะเวลาที่ใช้งานจริง

  • ไม่ต้องลงทุน Server ล่วงหน้า
  • ปรับทรัพยากรตามการใช้งาน
  • เหมาะกับงานที่ต้องการความยืดหยุ่น

Free Tier

ทดลองใช้บริการ Cloud บางประเภทโดยไม่มีค่าใช้จ่าย ภายใต้เงื่อนไขของ Oracle

  • เหมาะสำหรับนักศึกษา
  • เหมาะสำหรับนักพัฒนา
  • ใช้ทดลองสร้าง Resource และ Application

Enterprise

มีรูปแบบการซื้อเครดิตหรือข้อตกลงการใช้งานสำหรับองค์กร เพื่อวางแผนค่าใช้จ่ายระยะยาว

  • วางแผนค่าใช้จ่ายระยะยาว
  • เหมาะกับปริมาณการใช้งานขององค์กร
  • ขึ้นอยู่กับข้อตกลงกับ Oracle
ข้อควรระวัง: Free Tier ไม่ได้หมายความว่าบริการทั้งหมดใช้งานได้ฟรีโดยไม่มีข้อจำกัด ควรตรวจสอบเงื่อนไขและ Resource ที่สร้างขึ้นเพื่อป้องกันค่าใช้จ่ายที่ไม่คาดคิด
Pros & Cons

ข้อดีและข้อจำกัด

ข้อดี (Pros)

มีบริการ Cloud ครบวงจร ครอบคลุม Compute, Storage, Database, Networking, Security, Container, Analytics และ AI
มีจุดเด่นด้าน Database โดยเฉพาะ Oracle Database และ Autonomous Database
รองรับการขยายระบบ สามารถเพิ่มหรือลดทรัพยากรตามปริมาณการใช้งาน
มีระบบรักษาความปลอดภัย เช่น IAM, MFA, Cloud Guard, Firewall และการเข้ารหัสข้อมูล
มี Data Center หลายภูมิภาคทั่วโลก
รองรับ Kubernetes, Container, Serverless, Big Data, AI และ Machine Learning

ข้อจำกัด (Cons)

มีความซับซ้อนสำหรับผู้เริ่มต้น เนื่องจากมีบริการและการตั้งค่าจำนวนมาก
ต้องมีความรู้ด้าน Cloud และ Network เพื่อออกแบบและตั้งค่าระบบ
อาจเกิดค่าใช้จ่ายที่ไม่คาดคิด หากใช้งานเกินเงื่อนไข Free Tier
ต้องใช้เวลาเรียนรู้ระบบ โดยเฉพาะผู้ที่เปลี่ยนมาจาก AWS หรือ Azure
บริการบางประเภทมีข้อจำกัดตาม Region
ระบบขนาดใหญ่มีความซับซ้อนและอาจต้องใช้ผู้ดูแลที่มีความรู้เฉพาะด้าน
